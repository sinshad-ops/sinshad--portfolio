# Real-world data: safe workflow

This folder is for source notes, ingestion scripts, and provenance metadata. Existing project datasets are kept intact as synthetic baselines until public-source data is downloaded, validated, and analyzed.

Do not upload raw datasets to GitHub by default. Some are large or have specific terms. Publish download/processing code, cite the source, and include only a small sample when the license permits it.

For source choices and per-project caveats, see `../REAL_WORLD_DATA_UPGRADE.md` and `../real_world_data_sources.json`.
